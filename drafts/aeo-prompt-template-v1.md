# AEO 콘텐츠 요청 템플릿 (한국어 기준)

```
AEO 최적화 콘텐츠를 써 줘.

[주제] 짜파게티 — 키워드 묶음 [번호·이름], [편 수]편
[페르소나] 두 살 딸을 키우는 부모, 칼로리 신경 씀, 매운 음식 매우 좋아함
           → 글마다 주된 고민은 하나만 (예: 다이어트 편 = 칼로리)

[형식] 아래 순서로
  1. 제목: 질문형 또는 주제형, 핵심 키워드 포함
  2. 대표 Q&A: 첫 문장이 곧 확정 답
  3. 자주 묻는 질문(FAQ) [3~6]개
  4. 출처 (자료 이름 + 확인 날짜)
  5. 관련 키워드 한 줄

[길이 — 한국어 기준]
  - 대표 답: 2~3문장, 120~180자 (공백 포함)
  - FAQ 답: 1~2문장, 50~100자 (공백 포함)
  - 첫 문장은 40자 안팎, "~입니다 / ~합니다"로 끝나는 확정 문장
  - 한 문장에는 한 가지 정보만

[문장 규칙 — 한국어]
  - 첫 문장에 질문의 단어를 그대로 다시 씀 (예: "짜파게티 반개 칼로리는 약 305kcal입니다.")
  - "~일 수 있습니다", "~것 같습니다" 같은 흐린 끝맺음은 첫 문장에 쓰지 않음
  - 숫자는 아라비아 숫자 + 단위 (610kcal, 1,100mg, 2026년 10월 27일)
  - 영어·전문용어는 한글로 풀어 쓰거나 괄호로 설명 (예: 나트륨(짠맛 성분))

[필수]
  - 수치·날짜·제품명 넣기
  - 공식 자료(포장지, 농심 공식, 공공기관)로 확인하고 출처와 확인 날짜 표기
  - 조건·예외·비교 하나 이상 (예: 1개 기준 vs 100g당)

[금지]
  - 홍보 표현 ("최고", "꼭 드셔보세요", "인생 라면")
  - 확인 안 된 수치 → 빈칸 말고 "포장지 확인"으로 안내
  - 아이 건강에 대한 단정

[평가 기준] 직접답변 / 제목·구조 / 사실·근거 / 충실성 / 객관성 (각 10점)

[예시]
(잘 된 예시 한 편 붙여넣기)
```

## 길이 맞춘 예시

**Q. 짜파게티 반개 칼로리는 얼마인가요?**

짜파게티 반개(70g)의 칼로리는 약 305kcal입니다. 1봉(140g) 610kcal를 절반으로 나눈 값이며, 탄수화물은 약 48g, 나트륨은 약 550mg입니다. 반 봉만 먹을 때는 분말스프와 조미유도 절반만 넣어야 이 수치에 맞습니다.
→ 3문장 · 약 120자 (대표 답 기준)

**Q. 짜파게티 큰사발은 봉지보다 나트륨이 많나요?**

많습니다. 큰사발(123g)은 나트륨 1,220mg으로, 더 무거운 봉지(140g, 1,100mg)보다 120mg 많습니다.
→ 2문장 · 약 60자 (FAQ 답 기준)
